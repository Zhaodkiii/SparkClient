# 检查报告列表顶部筛选栏滚动吸附需求文档

> 文档性质：需求工单。本文用于描述 `ExaminationReportsListPage` 中检查报告分类筛选栏的滚动吸附交互。本文仅记录需求与验收标准，不直接修改代码。

## 1. 背景

当前检查报告列表页顶部筛选栏结构如下：

```swift
VStack(spacing: 0) {
    VStack(spacing: 12) {
        ExaminationReportFilterBar(selectedCategory: $selectedCategory)
            .padding(.horizontal, 16)
            .padding(.top, 8)
    }
    .padding(.bottom, 8)
    .background(Color(uiColor: .systemGroupedBackground))

    Divider()
        .opacity(0.35)
}
```

该区域承载检查报告分类筛选能力，例如全部、实验室检查、影像学检查、病理检查等。列表滚动时，筛选栏需要具备更稳定的顶部吸附行为，避免用户向上浏览历史报告后失去分类筛选入口。

## 2. 需求目标

1. 检查报告分类筛选栏参与列表滚动，但向上滚动到顶部后需要吸附停留。
2. 用户继续向上滚动列表时，筛选栏保持在顶部，不再随内容继续滚出屏幕。
3. 用户向下滚动或回拉列表时，筛选栏应随着列表内容同步变化，恢复自然滚动位置。
4. 筛选栏吸附时的顶部位置不能贴到屏幕最顶端，需要包含顶部导航区域和顶部 tab 栏高度。
5. 筛选栏下方的 `Divider` 需要与筛选栏一起吸附，保持视觉边界。
6. 吸附行为不能影响下拉刷新、搜索框、底部操作栏、列表卡片点击和筛选逻辑。

## 3. 滚动方向定义

为避免实现歧义，本文使用以下方向定义：

| 描述 | 用户手势 | 内容视觉变化 | 筛选栏要求 |
| --- | --- | --- | --- |
| 向上滚动列表 | 手指向上滑 | 列表内容向上移动，用户查看更早内容 | 筛选栏到达顶部后吸附停留 |
| 向下滚动列表 | 手指向下滑 | 列表内容向下移动，用户回到更新内容或触发回拉 | 筛选栏随列表同步变化 |

## 5. 吸附位置规则

筛选栏吸附顶部位置应基于页面真实顶部安全区域计算：

```text
stickyTop = navigationBarHeight + topTabBarHeight
```

要求：

1. 如果页面存在顶部 tab 栏，筛选栏吸附位置必须在 tab 栏下方。
2. 如果页面不存在顶部 tab 栏，筛选栏吸附位置应在导航栏下方。
3. 不允许筛选栏覆盖导航标题、返回按钮、系统搜索框或顶部 tab 栏。
4. `stickyTop` 需要兼容不同设备安全区高度。
5. 横竖屏或大字体场景下，吸附位置应随顶部区域实际高度变化。

## 6. 交互规则

1. 筛选栏未到达吸附位置前，应作为列表内容的一部分自然滚动。
2. 筛选栏顶部到达 `stickyTop` 后，继续向上滚动时固定在该位置。
3. 固定后列表卡片从筛选栏下方继续滚动，不应被筛选栏永久遮挡。
4. 用户向下滚动到列表顶部附近时，筛选栏解除固定并回到原始列表位置。
5. 筛选栏吸附或解除吸附过程不需要额外动画，以系统滚动自然表现为准。
6. 筛选栏选中状态、点击响应、横向滚动筛选能力保持不变。
7. 下拉刷新手势仍可触发，不应被吸附层拦截。

## 7. 实现建议

可选实现方向：

1. 使用 `ScrollView` + `GeometryReader` / preference key 监听筛选栏在全局坐标中的位置，并根据偏移量切换吸附状态。
2. 使用 SwiftUI 的 pinned section header 能力时，需要验证其顶部停留位置是否能正确避让导航栏和顶部 tab 栏。
3. 如使用 overlay 固定筛选栏，需要为列表内容补充等高顶部占位，避免卡片被固定筛选栏覆盖。
4. 顶部 tab 栏高度应由实际布局测量或统一布局常量提供，不建议写死为单一数值。
5. 筛选栏和 `Divider` 应作为同一个 sticky header 组件处理，避免分割线与筛选栏滚动不同步。

建议封装：

```swift
private var stickyFilterHeader: some View {
    VStack(spacing: 0) {
        VStack(spacing: 12) {
            ExaminationReportFilterBar(selectedCategory: $selectedCategory)
                .padding(.horizontal, 16)
                .padding(.top, 8)
        }
        .padding(.bottom, 8)
        .background(Color(uiColor: .systemGroupedBackground))

        Divider()
            .opacity(0.35)
    }
}
```

## 8. 验收标准

1. 首次进入页面时，筛选栏显示在列表顶部，样式与当前页面一致。
2. 向上滚动列表时，筛选栏到达顶部 tab 栏下方后固定停留。
3. 筛选栏固定后，继续向上滚动不会离开屏幕。
4. 向下滚动列表时，筛选栏随着列表内容同步恢复，不保持强制固定。
5. 筛选栏固定位置包含顶部 tab 栏高度，不遮挡顶部 tab 栏。
6. 筛选栏不遮挡报告卡片内容，列表滚动区域有正确顶部避让。
7. 筛选栏横向滚动和分类点击仍正常。
8. 下拉刷新仍正常触发。
9. 系统搜索框仍正常展示和输入。
10. 底部“手动添加”和“拍摄添加报告”操作栏不受影响。

## 9. 风险与注意事项

1. SwiftUI `safeAreaInset`、`searchable`、导航栏和自定义顶部 tab 栏组合时，顶部坐标可能因系统版本变化而不同，需要真机验证。
2. 如果用 overlay 实现吸附，需要避免重复渲染两个筛选栏导致点击错位。
3. 如果用 pinned header 实现，需要确认 pinned header 不会被导航栏或搜索框遮挡。
4. 顶部 tab 栏高度不能仅按视觉估算，应尽量从布局中读取或由上层统一传入。
5. 需要验证 iOS 15、iOS 16 及以上版本的表现是否一致。
