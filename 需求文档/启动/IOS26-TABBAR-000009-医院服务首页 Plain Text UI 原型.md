# IOS26-TABBAR-000009 医院服务首页 Plain Text UI 原型

> 对应需求工单：`IOS26-TABBAR-000009-医院首页与新Tab需求确认工单.md`  
> 原型类型：iOS 患者端 Plain Text UI 结构原型  
> 状态：Q1–Q21 已确认；本阶段只维护文档，不实现代码。  
> 设备基线：iPhone 竖屏；页面需要适配小屏设备、动态字体和无障碍阅读。

## 0. 原型使用规则

本文件是 `IOS26-TABBAR-000009` 的对应 UI 原型，以该工单最终问答为准。既有医院演示原型中与本工单冲突的内容，以本文件覆盖。

本期最终视觉定位：

- 医院是独立根 Tab。
- 医院首页是医院官方服务大厅。
- AI 导诊保留高亮主视觉，但本期点击只提示“功能正在实现”，不进入问答。
- 报告解读复用已有“新建会话 → 自动发送小任务 → 报告上传卡片”的完整流程。
- 预约挂号、线上问诊保留卡片，但点击提示“功能正在实现”。
- 常用科室固定展示：心内科、皮肤科、内分泌科。
- 院内医生智能体展示 3 位横向卡片，点击卡片或“去问 AI 助手”直接进入会话。
- 本期不显示“演示环境”标签，不显示虚假的通知红点。

## 1. 信息架构

```text
根 Tab
├── 健康
├── 医院  ← 本文件设计范围
│   └── 医院服务首页
│       ├── 医院身份与通知占位
│       ├── 当前就诊人 / 成员切换
│       ├── 四项核心服务
│       │   ├── 预约挂号：功能正在实现
│       │   ├── AI 导诊：高亮，功能正在实现
│       │   ├── 报告解读：进入已有报告解读对话流程
│       │   └── 线上问诊：功能正在实现
│       ├── 常用科室：心内科 / 皮肤科 / 内分泌科
│       └── 院内医生智能体：3 位横向卡片 / 查看全部
├── 消息
└── 设置
```

“医院”根 Tab 负责医院服务发现；“消息”根 Tab 负责统一消息列表。医院首页不复制消息列表，不复制 ChatThread，不复制报告解读小任务，也不复制医院医生智能体模型。

### 2.1 顶部医院身份

```text
┌──────────────────────────────────────┐
│ [医院 Logo]  天长市中医院      [🔔] │
│              官方医疗服务            │
└──────────────────────────────────────┘
```

规则：

- 医院默认取医院列表第一家；本期不显示医院切换按钮。
- 医院名称、Logo、背景图和服务属性优先来自服务端配置，演示默认配置作为兜底。
- 本期不显示“演示环境”标签。
- 通知铃铛为占位入口，无红点；点击显示“功能正在实现”。
- 医院身份区域不承担医院切换动作，避免与当前医院固定上下文冲突。

### 2.2 当前就诊人

```text
┌──────────────────────────────────────┐
│ 当前就诊人                           │
│ [头像]  演示患者 01                  │
│         男 · 32 岁             [切换]│
└──────────────────────────────────────┘
```

交互：

- 点击整张卡片或“切换”打开现有成员切换组件。
- 当前登录成员直接作为当前患者，不创建医院专用患者实体。
- 成员切换成功后保留医院首页滚动位置，刷新当前患者相关内容。
- 报告解读新会话和医生智能体新会话必须使用切换后的成员 ID。

### 2.3 四项核心服务

```text
┌────────┬────────┬────────┬────────┐
│预约挂号│ AI 导诊│报告解读│线上问诊│

│实现    │实现    │解读对话│实现    │
└────────┴────────┴────────┴────────┘
```

视觉规则：

- 四项服务横向四列同屏展示，复用效果图结构。
- 标题使用短文案，副文案使用一行短状态。
- AI 导诊保持高亮色和 AI 图标，但必须带“功能正在实现”标签。
- 报告解读是本期唯一确定的可用卡片。
- 预约挂号、线上问诊卡片保留展示，点击后统一提示，不进入空页面。

### 8.2 返回行为

```text
医院首页向下滚动到“院内医生智能体”
          ↓
切换到消息 Tab
          ↓
返回医院 Tab
          ↓
仍停留在“院内医生智能体”区域
```

保留内容：

- 当前滚动位置
- 当前就诊人
- 当前医院首页缓存内容
- 已展开/收起状态
- 后台刷新状态

不允许：后台刷新成功后无条件回到首页顶部，或切换患者后继续使用旧患者创建报告解读/医生会话。
