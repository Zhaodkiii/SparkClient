# 对话、AI Runtime 与工具调用需求

## 一、模块目标

本模块负责对话线程、消息读写、附件处理、AI Runtime 推理、工具调用、问报告和聊天同步。当前模块已拆为更细专题文档，本文保留为目录索引和模块边界。

## 二、对话、AI Runtime 与工具调用模块结构

```text
对话、AI Runtime 与工具调用/
├── 对话、AI Runtime 与工具调用需求.md
├── 对话线程与消息读模型需求.md
├── 消息发送、附件与同步管线需求.md
├── 消息卡片UI、对话列表.md
├── AI Runtime 推理编排需求.md
├── 工具调用与审计需求.md
└── 问报告与健康资源上下文需求.md
```

| 专题文档 | 关注范围 |
| --- | --- |
| `对话线程与消息读模型需求.md` | 线程列表投影、消息窗口、CoreData 读模型、StateStore 与线程设置数据契约 |
| `消息发送、附件与同步管线需求.md` | 消息发送、附件上传/OCR、outbox、同步、失败重试 |
| `消息卡片UI、对话列表.md` | 线程列表页、消息 CollectionView 宿主、气泡/MessageCards 渲染、长按菜单与 UI 瞬时状态 |
| `AI Runtime 推理编排需求.md` | 场景模型解析、本地/远端推理、流式事件、取消、工具能力降级 |
| `工具调用与审计需求.md` | ToolHub、工具定义、模型 tool_call、用户授权、审计和副作用 |
| `问报告与健康资源上下文需求.md` | 选择医疗资源、问报告 timeline、健康资源上下文注入 |
